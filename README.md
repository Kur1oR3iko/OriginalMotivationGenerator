# 墨尔本草稿 / Melbourne Drafts / メルボルン草稿

关于时间、身体、语言与观看的八件离线互动作品，使用 SwiftUI 构建，支持 iOS、iPadOS 和 Apple 芯片 Mac。短语作品从 `emu98` 关于页彩蛋中独立而来，保留225个动词、225个形容词、225个名词，以及遍历全部11,390,625种组合且不重复的生成算法。

根据设备首选语言自动选择界面：中文（包括简体与繁体语言偏好）使用简体中文，日文使用日文，其余使用英文。三个语言版本包含全部界面、辅助功能、日期格式与675个短语词条。短语以中文作为稳定存储形式，切换语言不会重置生成进度；日文使用形容词、名词、动词的自然词序。翻译源文件在 `Localization/`，执行 `python3 scripts/build_localizations.py` 生成标准 `.strings` 资源。

截图使用专用 Simulator 和以 `.screenshots` 结尾的独立调试包。`--capture --capture-page 0` 等参数只在 DEBUG 的截图包内启用样例数据，正式构建不可启用，也不读写正式包的个人记录。

应用启动后以横屏显示白底黑字短语，点击屏幕任意位置生成下一条。界面会根据 iPhone 或 iPad 的安全区和可用宽度自动调整字号，并始终保持单行。

在 Apple 芯片 Mac 上以“为 iPad 设计”模式运行时，支持适配窗口大小和全屏显示。点击后三个词同时以约 0.16 秒的翻动效果切换：动词和名词向上，形容词向下，不增加词间距；开启系统“减弱动态效果”时直接更新文字。

三指上划或下划都能在短语主页和“kurio最新力作（2）”设置页之间循环切换，翻页方向跟随手势，切换约 0.24 秒。设置页不显示返回按钮或手势提示文字，系统开启“减弱动态效果”时直接换页。设置页提供软件介绍和“时间的流速”模式，自动切换间隔可选 0.5 秒、1 秒、5 秒、10 秒、30 秒、1 分钟、5 分钟，设置会自动保存。打开设置或应用进入后台时暂停，返回后重新计时；点击短语会生成下一条并关闭自动切换。Mac 上可点击右上角页面切换图标或按 `⌘,` 在两页之间切换。

三指左右滑动在八个作品之间循环切换：原始动机生成器、25小时时钟、只能按一次、申请、死之钟、呼吸、没有拍下、休眠。上下滑动进入各自的设置页，横向切换设置页时也会切换到相邻作品的设置。横向翻页时，屏幕下方短暂显示八个页码小点。Mac 可使用方向键切换；短语、时钟及设置页也保留功能图标。离开短语主页时，自动生成暂停。

macOS 版、模拟器或连接外接键盘的 iPad 都可以直接使用方向键：`←` / `→` 循环切换八个作品，`↑` / `↓` 在当前主页和设置页之间翻页。输入文字时，方向键用于文本编辑；结束编辑后即可继续翻页。

25 小时时钟以 **2000 年 1 月 1 日 00:00 UTC** 为统一起点，每分钟 60 秒、每小时 60 分钟，每天 25 小时（90,000 秒），因此 `24:59` 之后才进入下一天的 `00:00`。日期从起点按这些 25 小时日递增，每周 7 天，每年 12 个月，月长与闰年按公历规则确定；显示日期会与现实公历日期不同。时区按真实当前时刻的 UTC 偏移换算，包含夏令时及半小时、四十五分钟时区。时钟设置可隐藏年月日、开启“显示秒钟”（`HH:mm:ss`），选择跟随系统、常用城市或搜索其他地区，选项自动保存。

声音对应关系：每次手动或自动生成新短语播放 `page`（1.6倍速，约0.44秒），一次性按钮首次成功保存记录后播放 `click`，提交申请时播放 `send`。时钟主页处于前台且显示秒钟时每秒播放轻声 `tick`，离开页面或进入后台停止。声音遵循设备静音设置；快速重复触发时重启当前音效，不叠加多份。前三种声音由 Kurio 提供，滴答声使用 Kenney 的 CC0 素材，来源和转换说明见 [声音说明](App/Sounds/CREDITS.md)。

时钟设置左侧显示所选时区下的当前月历，以周一为每周首日，并突出25小时时钟的当前日期。点击左上角日期标题，按日视图 → 月视图 → 年视图 → 日视图循环切换；点击月份或年份可进一步浏览，不会修改时钟时间。右侧默认只显示“跟随系统”和“其他时区”；点击“其他时区”才展开搜索和时区列表，选择后自动收起。列表有独立的滚动区域，默认最多显示五项，到墨尔本截止；窗口空间不足时进一步缩短，后面的时区及全部时区入口在列表内滚动查看。


“只能按一次”的主页最初只有一个居中的按钮。首次点击会先将按下日期和时区原子保存到应用数据目录，再播放内置咔哒声，按钮随即消失，中央淡入真实日期时间及同一时刻的25小时时间（“或者说是……”）。淡入只在首次按下时播放，之后切页返回或重新打开软件都直接显示记录。记录随应用重启和更新保留，不提供重置入口；两种显示都固定使用按下时的时区。介绍页文案为“要按下试试吗，你只有一次机会。”，下面是浅色小字“也许你已经按过了”。

“申请”替代原来的“信”。主页是一份申请进入空白页面的表单：填写申请人、申请理由，在右侧独立区域提交。经过随机2–5秒的等待后，申请始终获准，点击“进入”便留下纯白页面。所有文字和审批都在本地，不进行网络发送。表单和审批状态在当前应用会话中随翻页保留；返回时已到期的审批直接完成。输入工具栏的“完成”可结束编辑，恢复方向键翻页。设置页介绍是“进入一片空白，也需要被允许吗。”，点击“重新申请”清空内容并返回主页。

“呼吸”在按住屏幕期间实时延长黑线。线长按 `1 − exp(−吸气秒数 / 6)` 映射到可用宽度，约4秒达到49%、8秒达到74%，越接近边缘增长越慢。中央淡灰圆以线条增长曲线的1.15倍速度舒展。松手后，圆在1秒内缩小至消失，黑线在同一秒内退回左侧起点，留下完整的灰色痕迹；连续快速呼吸时，每次回收动画独立完成。开启“减弱动态效果”时改用1秒淡出。新线叠在已有线条上方，满屏后自动舍弃最早的底部线条。三指导航、离开页面或应用进入后台会取消尚未完成的吸气。每次松手后立即将线痕原子保存到本机，重新打开软件会恢复；满屏舍弃和设置中的“舍弃”也会同步保存。尚未松手的吸气和短暂动画不保存；多个窗口共享同一份线痕。 《呼吸》不播放音效。在支持Core Haptics的设备上，按住时提供柔和的低锐度触觉起伏，强度在约6秒内逐渐增加并维持较低上限；松手后用1秒减弱至停止，翻页、取消触摸及进入后台立即停止。无触觉硬件的设备和模拟器自动跳过触觉播放。

“没有拍下”提供实时相机取景。按下快门后倒计时三秒并模拟闪白，不拍摄、不保存任何照片，也不请求相册权限。相机只在该作品主页处于前台时运行，离开页面会停止取景并取消倒计时。无相机的设备显示提示；相机权限被拒绝时提供系统设置入口。介绍为“你决定记录下这一刻”。真实取景和闪白需在有相机的设备上检查。

“休眠”主页是灰色素描锁和“打扰并观察”按钮，左上角显示“已经生长x天x小时x分”。上锁期间按真实时间累积生长，包含查看锁屏、切换作品和关闭应用的时间；以30天为上限。灰色素描花草园包含72丛草和33株不同花型的植物，按固定种子和连续阶段长出茎、叶和花；30天的线性进度控制逐批出现的数量和密度。花草各自用约半天完成一次萌发、长叶和开花，第一天已有少量成熟植株；成熟后保留正常高度。之后新植株在空隙中陆续出现，半个月约有一半数量，30天填满苗圃。观察回退时按相反顺序撤回较晚出现的植株。 叶片有不同轮廓、叶脉和虫咬痕迹；部分老花低垂，地面逐渐出现落叶、枯枝、石头、苔藓和蛛网。苗圃积累30分钟后出现蚂蚁，3小时后有蜗牛，1天后有蝴蝶，7天后有鸟，14天后有兔子。打开观察后，鸟和蝴蝶陆续飞离，兔子藏回草丛，蜗牛慢慢缩回壳里；开启减弱动态效果时改用静止淡出。动物反应与观察时长一起保存，翻页或重启不会重复播放；重新上锁后开始下一次观察。

点击“打扰并观察”后显示花草园，每观察1秒，生长时间减少10分钟（600倍），计时与形态同步回退，最少为零。点击右上角“离开”重新上锁，从剩余进度恢复正常生长。观察时直接翻页、打开介绍或让应用进入后台，会暂停回退并保留未上锁状态；再次进入继续观察，只有“离开”按钮恢复生长。多个窗口同时观察也只按600倍计算。状态、剩余时间及植物种子本地持久保存，并迁移旧版休眠进度。介绍阐述“观看消耗生长时间”的思想及这些规则。

“死之钟”是第五个作品。未填写过资料时，无论从其他作品的主页还是设置页横向进入，都先在死之钟主页依次填写当前年龄、通过1–8000岁的滚轮选择预期寿命，阶段之间淡出切换。预期寿命小于当前年龄时显示“欢迎你，鬼魂先生/女生”，下方以较小字号显示“享受接下来额外的人生吧”；选择8000岁时显示“想不到能在这里遇见你，大蝽。”，其他情况显示剩余天数。活动以两列排列，列间距95点；第二列额外显示原文“与那个人再见一定的次数”，不作数字推算。相同年龄得到0天。输入与起算时刻保存在本机。设置页显示“关于活着的其他一些想法”，默认按北半球计算夏天，可切换南半球；点击“重新考虑我的生命”会清除设定并翻回主页重新填写。

死之钟使用普通24小时日，以填写时刻加上“预期寿命减当前年龄”的公历年数作为假定终点。周末计算尚未开始的星期六，夏天默认按北半球6月1日开始、可切换南半球12月1日。气象季节依据 NOAA NCEI 的说明（https://www.ncei.noaa.gov/news/meteorological-versus-astronomical-seasons）。每天1顿早餐、每年12本书、每年回老家2次均为明确的创作假设，不是调查数据或个人寿命预测；计算说明保留在仓库文档中，不在设置界面显示。

## 构建

需要 macOS、Xcode、CMake 3.20 或更高版本。App 的最低系统版本为 iOS / iPadOS 15.0；提交 App Store Connect 时需使用 Xcode 26 或更高版本和 iOS 26 SDK 或更高版本构建。

```sh
open OriginalMotivationGenerator.xcodeproj
```

仓库同时保留了 CMake 构建文件。GitHub Actions 会在 `main` 和 `release/testflight` 分支上执行无签名模拟器构建；Xcode Cloud 负责归档并发布到 TestFlight。

在 Xcode 中选择模拟器即可运行。若要安装到真机，请在项目签名设置中选择自己的开发团队，或生成项目时传入：

```sh
cmake -S . -B build -G Xcode -DOMG_DEVELOPMENT_TEAM=你的团队ID
```

生成进度和随机起点只保存在本机；横屏点击任意位置即可生成下一条短语。

时钟换算回归检查（不需要模拟器）：

```sh
swiftc App/Localization.swift App/Clock25.swift Tests/Clock25Tests.swift -o /tmp/omg-clock-tests
/tmp/omg-clock-tests
```

一次性记录持久化检查（使用独立临时目录，不消耗应用内的机会）：

```sh
swiftc App/Localization.swift App/OncePressStore.swift Tests/OncePressStoreTests.swift -o /tmp/omg-once-tests
/tmp/omg-once-tests
```

呼吸边界、休眠生命周期及申请状态检查：

```sh
swiftc App/Localization.swift App/InteractiveArtModels.swift Tests/InteractiveArtTests.swift -o /tmp/omg-interactive-art-tests
/tmp/omg-interactive-art-tests
```
